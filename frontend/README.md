# CamTech Frontend

Application Next.js pour le site CamTech.

## Démarrage local

1. `npm install`
2. `cp .env.example .env.local`
3. `npm run dev`

## Déploiement

### Vercel

- Connecter le dépôt à Vercel
- Définir la variable d’environnement : `NEXT_PUBLIC_API_BASE`
- Exemple : `https://votre-backend.vercel.app`

### Netlify

- Connecter le dépôt à Netlify
- Définir la variable d’environnement : `NEXT_PUBLIC_API_BASE`
- Exemple : `https://votre-backend.netlify.app`
